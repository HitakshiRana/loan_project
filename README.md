# loan_project

# 🏦 Loan Approval & Risk Prediction using Explainable AI

## 📌 Overview

This project is an AI-powered Loan Approval and Risk Prediction System developed using Machine Learning. The system predicts whether a loan application should be approved or rejected based on applicant information such as income, loan amount, CIBIL score, dependents, employment status, and assets. The project also integrates Explainable AI (XAI) to provide transparent and interpretable predictions.



## 🎯 Objectives

* Automate the loan approval process.
* Reduce manual effort and decision-making bias.
* Predict loan approval status accurately.
* Explain model predictions using Explainable AI.
* Provide a user-friendly web interface for real-time predictions.



## 🛠️ Technologies Used

* Python
* Pandas
* NumPy
* Scikit-learn
* Random Forest Classifier
* SHAP (Explainable AI)
* Streamlit
* Matplotlib
* Seaborn



## 📊 Dataset Features

The model uses the following features:

* Number of Dependents
* Education
* Self Employment Status
* Annual Income
* Loan Amount
* Loan Term
* CIBIL Score
* Residential Assets Value
* Commercial Assets Value
* Luxury Assets Value
* Bank Asset Value



## 🤖 Machine Learning Models

The following algorithms were evaluated:

* Logistic Regression
* Decision Tree
* K-Nearest Neighbors (KNN)
* Random Forest

Random Forest achieved the best performance and was selected as the final model.



## 📈 Model Performance

* Accuracy: 97%
* Evaluation Metrics:

  * Accuracy
  * Precision
  * Recall
  * F1-Score
  * Confusion Matrix



## 🧠 Explainable AI (XAI)

The project uses SHAP (SHapley Additive Explanations) to explain model predictions.

XAI provides:

* Feature contribution analysis
* Positive and negative impact of features
* Loan approval/rejection reasoning
* Improved transparency and trust



## 🌐 Streamlit Application

The trained model is deployed using Streamlit, allowing users to:

* Enter applicant details
* Predict loan approval status
* View approval probability
* Understand prediction explanations through XAI
